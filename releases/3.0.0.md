# Codex skills 3.0.0 (Unreleased)

This release publishes a focused catalog of 20 maintained engineering, product, documentation, review, and operations skills for current Codex and GitHub usage.

## Highlights

- Add nine reusable workflows for focused TDD, visual PR explanations, product-idea management, Polish and English UI copy, and architecture, backend, frontend, security/privacy, and test-coverage reviews.
- Modernize Git, GitHub Actions, debugging, documentation, release, regex, dependency, and VPS workflows.
- Rewrite every skill description around concrete user requests and invocation triggers.
- Refresh commit and pull request templates with exact PR creation and visual-evidence guidance.
- Add `agents/openai.yaml` discovery metadata to every published skill.
- Strengthen catalog validation for skill names, frontmatter, referenced files, body size, UI metadata, malformed YAML keys, and exact skill-token prompts.
- Reject stale `skills.json`, run CLI tests in CI, and refresh GitHub Actions to current major versions.

## Breaking changes

- Remove `agents-md`, `coding-guidelines-gen`, `coding-guidelines-verify`, `create-cli`, `plan-work`, `sessions-to-blog`, `ui-ux-pro-max`, and `video-transcript-downloader` from the published catalog.
- Existing local installations are not deleted automatically. The `init-ledger` CLI command remains available; only the `agents-md` skill is removed.

## Security

- Prefer GitHub connector context with explicit fallbacks and mutation gates in GitHub-related workflows.
- Add direct and transitive CVE/advisory auditing, dependency-path verification, patched-version selection, and time-bounded override guidance.
- Add dependency release-age, lockfile, provenance, integrity, lifecycle-script, and dependency-review checks.
- Detect the active VPS firewall and keep package refreshes, restarts, pruning, and configuration changes behind explicit approval.

## Upgrade notes

- Review locally installed removed skills before deleting them; upgrading the catalog does not modify an existing skills directory.
- Skill contributors must add valid `agents/openai.yaml` metadata and install PyYAML before running the local validator.

## Verification

- `python scripts/build_skills_json.py --check`
- `python -m unittest discover -s scripts -p "test_*.py"`
- `python scripts/validate_skills.py`
- `python scripts/check_invisible_chars.py --all`
- `node --test cli/test/cli.test.js`
